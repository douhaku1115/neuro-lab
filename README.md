# 神経ラボ（Neuro Lab）

ショウジョウバエの脳を、神経細胞 1 個から脳まるごとまで、9 つの段階で動かして確かめるブラウザ教材です。
**開くだけで動きます:** https://douhaku1115.github.io/neuro-lab/

| 段 | 内容 |
|---|---|
| 1 加重 | たくさんの入力を、1 個のニューロンが足し合わせる |
| 2 側方抑制 | 隣どうしが抑えあうと、ちがいが強調される |
| 3 リング | 円環に繋ぐと、「向き」の記憶が生まれる |
| 4 コンパス | 回った量を足し続けると、向きになる |
| 5 本物の配線 | 実測したハエの脳の配線（FlyWire）で動かす |
| 6 全脳 | 脳まるごと 13.9 万個（甘味 → 口、苦味スイッチ、触角 → 身づくろい、迫る影 → 逃げる） |
| 7 目 | 動きの向きを感じる細胞（T4・T5） |
| 8 歩く | 6 本の脚をリズムで揃える |
| 9 脳で動く | 目で見て、よけて、ごちそうへ（実験中） |

段 5〜9 は、あらかじめ計算した結果を再生しています。

## 出典
- FlyWire 成虫全脳コネクトーム v783: Dorkenwald ら 2024 / Schlegel ら 2024（Nature）
- 全脳の計算モデル: Shiu ら 2024（Nature）
- 視覚系モデル flyvis: Lappalainen ら 2024（Nature）
- 体の物理シミュレーション FlyGym（NeuroMechFly v2）: Wang-Chen ら 2024（Nature Methods）
- 身づくろいの関節角度の記録: NeuroMechFly（Lobato-Rios ら 2022, Nature Methods）
